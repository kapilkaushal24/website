Vizo homepage screenshot reference crops

These files are crops from the supplied flattened screenshot (1672 x 941).
They are NOT original layered design assets and do not have transparent backgrounds.
The main hero artwork contains several overlapping objects and a person; this crop preserves
the combined artwork as a reference. For a production Next.js build, use a properly licensed
hero image or recreate/source the subject and decorative objects as separate assets.
Small icons and text can be recreated cleanly with SVG / lucide-react rather than using these crops.
